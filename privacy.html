2. Scope of This Privacy Policy

This Privacy Policy describes the data practices of the MiniDroid plugin and the MiniDroid developer.

It applies to:

  • the MiniDroid plugin distributed for ChatGPT and Codex;
  • the MiniDroid skills included in the plugin;
  • the MiniDroid project website and legal pages;
  • direct support communications with the MiniDroid developer.

It does not govern independent processing performed by OpenAI, GitHub, internet service providers, operating-system providers, email providers, or other third-party services.

3. Plugin Architecture

The current MiniDroid plugin is a skills-only plugin.

It provides technical instructions, development knowledge, documentation, reference material, project context, and a bundled MiniDroid runtime snapshot.

The current version does not use a developer-operated remote MCP server to receive user prompts, conversations, files, or account information.

4. Categories of Personal Data Collected

4.1 Data collected through normal plugin use

The MiniDroid developer does not intentionally collect personal data directly from users through ordinary use of the skills-only plugin.

In particular, the MiniDroid developer does not intentionally collect or request:

  • full ChatGPT or Codex conversation histories;
  • raw conversation transcripts;
  • precise location or GPS data;
  • contact lists;
  • advertising identifiers;
  • browsing histories;
  • behavioral profiles;
  • unrelated account information.

4.2 Information voluntarily provided directly to the developer

If you contact the MiniDroid developer directly, for example by email, the following categories of information may be received:

  • your name, if you provide it;
  • your email address;
  • the content of your communication;
  • technical information contained in a bug report;
  • source-code snippets voluntarily provided by you;
  • log excerpts voluntarily provided by you;
  • screenshots voluntarily provided by you;
  • project files voluntarily provided by you.

This information is provided voluntarily and is not required for ordinary installation or use of the MiniDroid plugin.

5. Restricted Data

MiniDroid does not require and is not intended to collect, solicit, or process the following categories of restricted information:

  • payment-card information;
  • protected health information (PHI);
  • government identification numbers;
  • passwords;
  • API keys;
  • authentication tokens;
  • MFA or one-time authentication codes;
  • private cryptographic keys or similar authentication secrets.

Please do not provide this information to the MiniDroid developer through bug reports, logs, screenshots, emails, source files, or other communications.

6. Sensitive or Special-Category Personal Data

MiniDroid does not require sensitive or special-category personal data for its stated purpose.

Users should not provide information concerning health, biometric identity, racial or ethnic origin, political opinions, religious or philosophical beliefs, trade-union membership, sexual orientation, or other legally protected sensitive categories unless there is an exceptional and lawful reason to do so.

7. Purposes of Processing

Personal information voluntarily provided directly to the MiniDroid developer may be used only for purposes reasonably related to the user's request, including:

  • responding to a support request;
  • investigating a reported MiniDroid bug;
  • diagnosing a compatibility problem;
  • responding to a security report;
  • maintaining and improving MiniDroid;
  • responding to legal obligations where required by law;
  • preventing abuse or protecting the security of the project.

Personal information is not collected for unrelated secondary purposes.

8. Data Minimization

MiniDroid follows a data-minimization approach.

The plugin is designed to use only information that is relevant to the user's specific technical request.

MiniDroid does not request broad personal profiles, complete conversation histories, accumulated prior-turn data, or unrelated personal information "just in case."

9. Categories of Recipients

The MiniDroid developer does not sell personal information.

Personal information voluntarily sent directly to the developer may be accessible to the following categories of recipients only where necessary:

  • email or hosting providers used to receive or store the communication;
  • technical service providers used only where reasonably necessary to investigate the user's request;
  • professional advisers where necessary for legal, security, or compliance purposes;
  • public authorities where disclosure is required by applicable law.

Personal information is not intentionally shared with advertising networks, data brokers, or behavioral-marketing providers.

10. Data Retention

10.1 Plugin usage

The current skills-only MiniDroid plugin does not operate a developer-controlled remote database containing users' plugin conversations, prompts, or usage history.

10.2 Direct support communications

Personal information received directly through support emails or technical support communications will normally be retained for no longer than 12 months after the last communication.

Information may be deleted earlier when it is no longer required.

Information may be retained for longer only where reasonably necessary to:

  • comply with a legal obligation;
  • establish, exercise, or defend legal claims;
  • investigate a security incident;
  • maintain a record of an unresolved technical or security issue.

10.3 Deletion requests

Where legally applicable, a user may request deletion of personal information directly controlled by the MiniDroid developer.

Valid deletion requests will be handled without undue delay, subject to applicable legal retention requirements.

11. Tracking, Analytics, and Behavioral Profiling

The MiniDroid plugin does not contain developer-operated:

  • behavioral advertising;
  • advertising trackers;
  • cross-site tracking;
  • cross-app tracking;
  • user fingerprinting;
  • behavioral profiling;
  • marketing analytics;
  • surveillance functionality.

The MiniDroid developer does not intentionally collect query patterns, timestamps, IP addresses, or similar metadata for profiling or advertising purposes through the plugin.

12. Cookies

The MiniDroid project does not intentionally set its own analytics, advertising, or behavioral-tracking cookies through its static project or privacy-policy pages.

Third-party hosting platforms may use their own cookies or technical mechanisms according to their own privacy policies.

13. OpenAI

When MiniDroid is used through ChatGPT, Codex, or another OpenAI product, OpenAI may process information as necessary to operate its services.

Such processing is controlled by OpenAI and is subject to the applicable OpenAI privacy documentation, terms, settings, and policies.

The MiniDroid developer does not receive a user's full OpenAI conversation history merely because the user installs or uses the MiniDroid plugin.

14. GitHub and Other Third-Party Services

MiniDroid may contain links to GitHub or other software-development resources.

When a user intentionally visits or uses a third-party service, that provider may process information independently according to its own privacy policy.

For example, a web-hosting provider may process ordinary network information such as IP addresses, browser information, request timestamps, and requested URLs as part of operating its service.

Such third-party processing is not performed by the MiniDroid plugin itself.

15. Local Files and Project Data

MiniDroid is a developer tool intended to work with technical materials such as source code, APKs, logs, runtime files, build files, and configuration files.

Local files processed on the user's own system are not automatically sent to the MiniDroid developer merely because MiniDroid accesses or modifies them locally.

Users remain responsible for deciding which files or technical information they intentionally provide to ChatGPT, Codex, GitHub, the MiniDroid developer, or any other third party.

16. User-Provided Logs, Files, and Screenshots

Before voluntarily sharing logs, screenshots, project archives, configuration files, or source code, users should review them and remove unnecessary:

  • personal information;
  • passwords;
  • API keys;
  • access tokens;
  • private keys;
  • authentication cookies;
  • other confidential information.

17. Optional External Downloads

MiniDroid may support workflows involving optional software components or Android compatibility resources.

Where the user intentionally requests an external download, the external provider may receive the technical network information necessary to deliver that resource.

MiniDroid does not intentionally send unrelated personal information to such providers.

18. Google Components

If optional Google-related components are supported, any installation must be explicitly initiated by the user and use an appropriate and lawful source.

Google or another external provider may independently process data when its services are intentionally used. Such processing is governed by that provider's own privacy policies.

19. Security
